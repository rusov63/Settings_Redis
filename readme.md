# Settings Redis

Проект содержит конфигурационные файлы и инструкции по установке и настройке Redis:
- **Readme_installationRedis.MD** - пошаговое руководство по установке Redis
- **Readme_redisConf.MD** - документация по настройке Redis
- **redis.conf** - основной конфигурационный файл с параметрами Redis

Используется для быстрой настройки Redis в новых проектах.
